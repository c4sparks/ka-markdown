Ka - 网页转Markdown —— 使用指南

① 单页转换（最常用）

  1. 打开想转换的网页，点击浏览器工具栏上的「Ka - 网页转Markdown」图标
  2. 弹窗会自动把当前页转成 Markdown，结果可直接编辑；右上角可切 👁 预览 / ✏ 编辑 查看渲染效果
  3. 点 复制 或 ⬇ 下载 拿走结果；底部 全屏编辑 可换到大编辑器
  4. 范围可切换「主要内容 / 整个页面」；「⟳ 重新转换」可换范围后重转
  5. 编辑器工具栏可切换 👁 预览（渲染后的效果，图片能直接显示）/ 分屏（左编辑右预览）/ ✏ 编辑（Markdown 原文）；在预览 / 分屏下编辑内容，预览会实时跟随更新；勾选设置里的「转换后显示预览面板」后，转换完成会直接进入预览视图

② 右键菜单

在任意网页上点右键 →「将本页转换为 Markdown」→ 二级菜单可选「转换主要内容 / 转换整页」，选后自动打开全屏编辑器展示结果。

③ 区域转换

只转页面上的某一块内容，有两种方式：

  • 框选文字：用鼠标选中一段内容 → 右键 →「将选中内容转换为 Markdown」
  • 点选区域：点弹窗的「⬚ 区域转换」→ 回到页面，把鼠标移到要转的区块上（会高亮蓝色框）→ 点击，自动转换该区块；按 Esc 可取消

区域转换同样遵循「转换内容」设置（图片 / 链接 / 来源说明）；你明确点选的区域会原样转换，不会自动过滤其中的导航 / 页脚。

④ 全屏编辑器

更大的编辑区，方便继续修改、排版；改完再复制 / 下载。也可以把别处的 Markdown 粘贴进来整理。

工具栏的「主要内容 / 整个页面」点一下就会按所选范围直接抓取当前标签页——切换范围即自动重新转换；「⟳ 转换当前标签页」可在同一范围下再次转换。

⑤ 批量转换

  1. 切到顶部「批量转换」标签
  2. 在网址列表里每行粘贴一个地址（# 开头的是注释，会跳过）
  3. 可选填「基地址」：列表里非完整 URL 的行会自动拼接成完整地址
  4. 选好范围 → 点「▶ 开始批量转换」，每个页面自动转成并下载一个 .md 文件，日志实时显示成功 / 失败

首次批量下载时浏览器可能询问「允许多个文件下载」，点「允许」即可，之后不再询问。

⑥ 转换设置

「设置」页可配置转换选项，改动即时保存，所有转换入口共用同一套设置：

  • 转换内容：包含图片 / 包含链接 / 添加来源说明 —— 决定 Markdown 里保留哪些内容
  • 转换后行为：自动复制 / 自动下载 / 显示预览面板 —— 转换完成后的自动操作；其中「显示预览面板」勾选后，转换完直接展示渲染预览，不勾选则停留在编辑视图（随时可用工具栏的「👁 预览」手动查看）

常见问题

  • chrome://、扩展商店等浏览器内部页面无法转换（浏览器安全限制，弹窗会提示）
  • 所有转换都在本机完成，不上传任何数据，可离线使用
  • 批量下载的 .md 文件名取自网页标题并附加时间戳（如 文章名-20260807-1430.md），非法字符会被自动替换；重复下载同一篇不会重名覆盖
