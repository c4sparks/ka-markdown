# Ka - 网页转Markdown（浏览器扩展）

一键把当前网页转换成 Markdown，支持**编辑、复制、下载、批量转换**。

适用于 Chrome / Edge 等 Chromium 内核浏览器，全中文界面，纯本地运行（无网络请求、无数据上传）。

弹窗、编辑器等扩展界面自动跟随系统深浅色（Windows 的应用模式 / 系统主题），预览区则跟随源网页自身配色。

## 功能

- **工具栏图标**：点击后自动把当前标签页转换为 Markdown
  - 支持切换「主要内容区 / 整个页面」两种范围
  - 结果在弹窗里直接编辑或**渲染预览**（图片直接可见），然后复制或下载 `.md` 文件
  - 「全屏编辑」把内容送进更大的编辑器页面
- **右键菜单**：在任意网页上右键 →「将本页转换为 Markdown」→ 二级菜单可选「转换主要内容 / 转换整页」，自动打开全屏编辑器
- **区域转换**：只转页面上的某一块内容
  - 框选一段文字 → 右键 →「将选中内容转换为 Markdown」
  - 点弹窗「⬚ 区域转换」→ 回到页面点选要转的区块（悬停高亮，`Esc` 取消）
- **全屏编辑器**：
  - 大编辑区，工具栏可切换「👁 预览 / 分屏 / ✏ 编辑」三种视图；预览实时渲染 Markdown，图片、表格、代码块都能直接看到，背景自动跟随源网页主题（白页白底、黑页黑底）；在预览 / 分屏下编辑内容时，右侧预览实时跟随更新
  - 工具栏「主要内容 / 整个页面」点一下即按所选范围抓取当前标签页——切换范围自动重新转换；「⟳ 转换当前标签页」可在同一范围下重转
  - 改完可复制 / 下载
  - **批量转换**：粘贴一组网址，逐个自动转换并下载成 `.md` 文件，带进度条和结果日志
- **转换选项（设置页）**：可配置 HTML 内容的处理和格式化方式
  - `包含图片`：关掉后转换结果不保留图片
  - `包含链接`：关掉后链接只保留文字，不带地址
  - `添加来源说明`：在开头附上页面标题与来源地址（默认开）
  - `自动复制到剪贴板`：转换完成后自动复制（弹窗 / 编辑器）
  - `自动下载`：转换完成后自动下载 `.md` 文件（弹窗 / 编辑器 / 右键菜单）
  - `转换后显示预览面板`：勾选后转换完成直接展示渲染预览；不勾选则停留在编辑视图（随时可用「👁 预览」手动查看）
- 转换质量针对文档站做了优化：
  - 自动识别正文区域，忽略导航、页眉、页脚；页面没有语义容器时按"散文块最多、最紧凑"的区块兜底，保证「主要内容」和「整个页面」结果不同
  - 代码块带围栏语法高亮标记（识别 `language-*` 与 Sphinx 的 `highlight-*`）
  - 表格转换为 Markdown 表格，相对链接 / 图片自动补全为绝对地址
  - 懒加载图片（只有 `data-src` / `data-original` / `srcset`，或 `src` 是占位图）也能转换出来
  - 标题右侧的 `¶` 锚点自动清理

## 安装

1. 打开浏览器地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `markdown-extension/`
4. 安装完成后，工具栏会出现「Ka - 网页转Markdown」图标

重新加载代码后，回到 `chrome://extensions` 点一下扩展卡片上的「刷新」即可。

## 使用

### 单页转换
- 打开目标网页 → 点击扩展图标 → 得到 Markdown → 编辑 / 复制 / 下载
- 或：网页上右键 →「将本页转换为 Markdown」→ 二级菜单选「转换主要内容 / 转换整页」→ 自动打开全屏编辑器

### 区域转换
- 框选文字：选中一段内容 → 右键 →「将选中内容转换为 Markdown」
- 点选区域：点弹窗「⬚ 区域转换」→ 页面进入选取模式，悬停会高亮蓝色框 → 点击要转的区块即自动转换并打开编辑器；`Esc` 取消
- 区域内容遵循「转换内容」设置；你点选的区域原样转换，不过滤导航 / 页脚

### 转换选项
- 弹窗右上角的 **⚙**（或编辑器顶部的「设置」标签）进入设置页
- 勾选 / 取消对应的开关，改动即时保存，之后所有转换（弹窗、右键、批量）都按当前设置执行

### 批量转换
1. 打开「全屏编辑器」→ 切到「批量转换」
2. 在网址列表里每行粘贴一个地址（`#` 开头的是注释，会跳过）
3. 可选：填「基地址」，列表里非完整 URL 的行会自动拼接成完整地址
4. 选择范围 → 点「▶ 开始批量转换」
5. 每个页面会在后台标签页里打开、转换、下载、关闭，日志实时显示成功 / 失败

> 批量下载时，浏览器可能第一次询问「允许下载多个文件」，点击**允许**即可，之后不再询问。

> 下载的 `.md` 文件名取自网页标题并附加时间戳，重复下载同一篇时不会重名覆盖。

## 文件说明

```
manifest.json            扩展清单（Manifest V3）
background.js            后台：右键菜单入口
content.js               核心转换器（注入到网页，Turndown + 自定义规则）
shared.js                公共工具（注入 / 文件名清洗 / 下载）
preview.js               渲染预览（marked + sandbox iframe，弹窗 / 编辑器共用）
lib/turndown.js          HTML→Markdown 引擎（本地打包）
lib/turndown-plugin-gfm.js  表格等 GFM 支持
lib/marked.min.js        Markdown→HTML 渲染引擎（本地打包，供预览用）
theme.css                界面主题变量（弹窗 / 编辑器共用，跟随系统深浅色）
popup.html/.css/.js      工具栏弹窗
editor.html/.css/.js     全屏编辑器 + 批量转换
icons/                   扩展图标（tools/make-icons.js 生成）
```

## 权限说明

- `activeTab` + `scripting` + `host_permissions:<all_urls>`：需要向当前 / 批量打开的页面注入转换脚本
- `downloads`：批量保存 `.md` 文件
- `storage`：保存设置与弹窗→编辑器的内容传递
- `contextMenus`：右键菜单

数据只在本机处理，不上传任何内容。

## 设置存储

所有选项统一存在扩展的 `chrome.storage.local` 的 `md_settings` 里（`scope` / `images` / `links` / `header` / `autoCopy` / `autoDownload` / `showPreview`），设置页修改后即持久化；缺字段时按默认值补齐。默认值见 `shared.js` 的 `MD_SETTINGS_DEFAULTS`。
